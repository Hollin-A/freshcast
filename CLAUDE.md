## Agent skills

### Issue tracker

Issues live in GitHub Issues for `Hollin-A/freshcast` (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), used alongside the existing `area:*` / `type:*` labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `CONTEXT.md` + system-wide ADRs in `docs/adr/`. See `docs/agents/domain.md`.
